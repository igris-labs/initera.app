## What Initera keeps together

Use Initera to plan projects, track issues, organize cycles, and record time in one workspace. You can use the desktop app without creating an online account.

## Check the installed version

Open the account menu, then choose **Help → About**. Read **Application version** before you report a bug or compare behavior with a guide.

![About dialog with application version, license, and credits](/images/app/settings-about.png)

## License and source

Initera uses the MIT License. Select **MIT License** in About to read the license text. The source code is available in the [Initera repository](https://github.com/igris-labs/initera.app).

If you want to work on the source, start with `README.md` and `CONTRIBUTING.md` in the repository root. Those files describe the pnpm workspace, desktop app, docs app, checks, and contribution process.

## Where work lives

The installed app stores its database and uploaded media in the Initera folder shown under **Settings → Workspace**. Keep the database and media together if you inspect or move local files.

Use [Backups and restore](/reference/backups) to make a restorable copy. A portable export includes managed images; the database file on its own does not.
