## Name and author

**Initera** is written by **Rahul Vashishtha** under **Igris Labs**, his personal laboratory.

The app lets you plan projects, track issues, organize cycles, and record time in a local workspace. You can use the installed desktop app without creating an online account.

## Check the installed version

Open **Settings → About**. Read **Application version** before you report a bug or compare behavior with a guide. The version in your installation can differ from the version in a development checkout.

![About section with version, license, author, and Igris Labs credit](/images/app/settings-about.png)

## License and source

Initera uses the MIT License. Select **MIT License** in About to read the license text. The `LICENSE` file in the repository root names Rahul Vashishtha as copyright holder.

If you want to work on the source, start with `README.md` and `CONTRIBUTING.md` in the repository root. Those files describe the pnpm workspace, desktop app, docs app, checks, and contribution process.

## Where work lives

The installed app stores its SQLite database and uploaded media in its application data folder. Open **Settings → Workspace** to see the folder path on your machine. Keep the database and media together if you inspect or move local files.

Use [Backups and restore](/reference/backups) to make a restorable copy. A portable export includes managed images; the database file on its own does not.
