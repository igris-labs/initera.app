## How shortcuts work

Press a letter shortcut while focus is outside an input or editor. A sequence such as **G** then **E** means press G, release it, then press E. On macOS, **⌘** means Command. On Windows and Linux, use **Ctrl** for the same modifier.

Press **?** to open the shortcut list in the command bar. Hover a button to see its shortcut when it has one. If a letter does nothing, leave the text field or close the dialog before you try again.
