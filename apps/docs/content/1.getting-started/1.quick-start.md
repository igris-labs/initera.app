## Start with a workspace

On first launch, enter **Your name** and a **Workspace name**. Use your own name: comments, project updates, and activity records show it. A workspace holds its own issues, projects, labels, cycles, views, and settings.

After setup, check the name at the top of the left sidebar before you create work. If you use more than one workspace, this check prevents you from putting an issue in the wrong place.

To add a workspace, select the plus button beside the workspace name. To switch, select the name and choose a workspace from the menu.

![Workspace picker with the current workspace marked](/images/app/workspace-picker.png)

Read [Workspaces](/getting-started/workspaces) for switching, identity, and local data storage.

## Create your first issue

1. Select **Create issue** in the top right. Press **C** if you prefer the keyboard and focus is outside a text field.
2. Enter a title that describes the work, such as “Review the export dialog.”
3. Choose a status and priority. You can leave the project, labels, estimate, and dates empty.
4. Add context in the description if the title needs an explanation.
5. Select **Create issue**.

![Create issue dialog with title, description, and property controls](/images/app/create-issue.png)

After you save the issue, find it in **All issues** and open its row. Its identifier appears near the title. Use that identifier when you search, discuss the work, or link another issue. Select a property in the right panel to change it. Use **Edit issue** for the title, description, and dates. See [Create an issue](/issues/creating-issues) for the full composer flow and draft recovery.

Open **All issues** in the sidebar to see the issue among other work. **Active** shows unfinished issues; **All** includes completed work. Use the filter button when the list grows.

![All issues in the list layout](/images/app/issues-list.png)

## Add a project

Create a project when several issues serve one goal. Select the plus button beside **Projects** in the sidebar, or open **Projects** and select **New project**. Enter a name and a two-to-eight-letter identifier. The identifier becomes the prefix for issues you assign to that project.

Add a summary, dates, or a milestone if you know them. You can fill the rest in after creation. Open your issue, select its **Project** property, and choose the new project. The app asks how to handle the issue identifier if the move changes its prefix. Your workspace setting controls whether that question appears.

Read [Create a project](/projects/creating-projects) for every field in the composer. The [Projects](/projects/projects) guide covers the overview, resources, milestones, structure, and project updates.

## Find your work

Press **⌘ K** on macOS or **Ctrl K** on Windows and Linux. Type an issue identifier, issue title, project name, or action. Use the arrow keys to select a result and **Enter** to open it. Press **Escape** to close the command bar.

![Command bar with actions for the issue list](/images/app/command-bar.png)

Press **?** outside a text field to see available shortcuts. The [Command bar](/reference/command-bar) and [Keyboard shortcuts](/reference/keyboard-shortcuts) guides cover search modes and page actions.

## Save a copy of your work

In the installed desktop app, open **Settings → Backups**. Select **Create backup** for a restorable copy in the app data folder. Select **Export workspace** when you need a file to keep elsewhere or move to another computer. The export includes uploaded images. See [Backups and restore](/reference/backups) before you import or restore a file.
